# Fairwashing Attacks on Explainable Machine Learning

## Overview

This project demonstrates how explanations generated by Explainable Artificial Intelligence (XAI) techniques such as SHAP and LIME can be manipulated without changing the underlying machine learning prediction.

The project focuses on a healthcare prediction scenario using the Pima Indians Diabetes Dataset. A biased XGBoost model is intentionally created to over-rely on the feature **Age**, after which a perturbation-based fairwashing attack is performed to hide this bias from explanation systems.

The work combines:
- Machine Learning
- Explainable AI (XAI)
- Adversarial Manipulation
- Fairness Analysis
- Visualization and Interpretation

---

## Problem Statement

Modern machine learning systems often use post-hoc explanation methods like SHAP and LIME to improve interpretability. However, these explanation systems may themselves be vulnerable to manipulation.

This project investigates the following question:

> Can explanations be changed while keeping the model prediction unchanged?

To answer this, a fairwashing attack is implemented where:
- The prediction remains identical
- The explanation changes significantly
- The biased feature attribution is hidden

---

## Objectives

- Train interpretable and black-box ML models
- Analyze model explanations using SHAP and LIME
- Evaluate stability of explanations under noise
- Inject intentional bias into a machine learning model
- Perform a fairwashing attack on SHAP explanations
- Evaluate attack effectiveness across the dataset

To evaluate robustness of explanations, a stability stress test is performed.

## Procedure
- Add small Gaussian noise (5%) to patient data
- Generate LIME explanations repeatedly
- Measure how often the top explanation feature changes

## Purpose
This experiment evaluates whether explanations remain consistent under slight input perturbations.

# Bias Injection

A biased training distribution is intentionally created.

## Method
Older diabetic patients are oversampled during training.

As a result:
- The model begins to disproportionately rely on the feature **Age**
- SHAP analysis confirms that Age becomes a dominant feature

This simulates unfair decision-making behavior in machine learning systems.

---

# Fairwashing Attack

## Goal

Manipulate feature explanations while preserving predictions.

The attack attempts to:
- Keep prediction unchanged
- Reduce SHAP attribution for Age
- Shift attribution toward Glucose

---

## Attack Strategy

A perturbation-based greedy search is used.

### Perturbed Features
- Age ↓
- Glucose ↑

### Constraints
- Prediction must remain unchanged
- Perturbations must remain bounded within epsilon budget

---

# Evaluation Metrics

The attack is evaluated using multiple metrics.

## 1. Cosine Similarity
Measures similarity between original and perturbed SHAP explanations.

Lower similarity indicates stronger explanation manipulation.

---

## 2. L∞ Norm
Measures perturbation magnitude.

Used to evaluate invisibility of changes.

---

## 3. Prediction Preservation
Checks whether the model prediction remains unchanged after perturbation.

---

## 4. Feature Attribution Shift
Measures whether the dominant feature changes:
- Age → Glucose

# Results

## LIME Stability Test
The stability analysis shows that explanations can change under small perturbations, indicating potential instability in local explanation methods.

---

## Fairwashing Attack (Single Instance)

Results show:
- Prediction remains unchanged
- SHAP explanation changes significantly
- Dominant feature shifts from Age to Glucose

This demonstrates successful explanation manipulation.

---

## Population-Level Analysis

### Results
- Total Test Patients: 154
- Vulnerable Patients: 45
- Successful Attacks: 15
- Failed Attacks: 30

### Attack Success Rate
33.3%

This shows that approximately:
> 1 in 3 biased explanations can be manipulated without changing predictions.
